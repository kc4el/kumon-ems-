Frontend: delete dead markup, point import at the real endpoint, drop confirms for low-risk self-saves, add dirty-tracking + inline errors + honest password rules. Every task TDD with the repo's file-content test pattern (`api/test_settings_frontend.py`) plus real API tests where behavior changes.
